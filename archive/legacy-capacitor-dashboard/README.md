# Legacy Capacitor Android Dashboard

This directory preserves the former Capacitor Android implementation for
historical reference and migration troubleshooting. It is no longer part of
the active web build and must not be used to publish Android releases.

The supported Android client is `mobile-app/` (React Native + Expo). The
browser dashboard remains in `web/` and is built with React + Vite.

- Former application id: `com.ezycode.litellm`
- Archived native project: `android/`
- Archived Capacitor configuration: `capacitor.config.json`
- Archived native plugin: `plugins/`
