fix(mobile-app): R9 fourth audit — broken initial URL, double /admin path, limit mismatch

Final deep code review via code-reviewer sub-agent.

#45 (HIGH) SetupScreen broken initial URL:
  useState('http://') as default — clicking start without editing saved a
  malformed URL with no host, causing all API requests to fail with NETWORK
  error. User got stuck since URL was non-empty (setup screen skipped).
  Changed to empty string; falls through to dev default.

#46 (MEDIUM) getBaseUrl double /admin path:
  client.ts unconditionally appended /admin. If user pasted
  http://server:4001/admin (natural), result was /admin/admin causing 404s.
  Added regex check to use URL as-is if /admin suffix already present.

#47 (LOW) getLogs default limit mismatch:
  client.ts default was 50, store default was 100. Latent trap if client
  called directly. Aligned both to 100.

Wiki: updated mobile-app-performance.md (sections 45-47) and log.md.
Validation: npx tsc --noEmit passes clean.
