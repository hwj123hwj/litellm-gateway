fix(android): R10 allow cleartext HTTP traffic in release builds

Android 9+ blocks HTTP traffic by default. The main (release) AndroidManifest
lacked usesCleartextTraffic and a network security config — only debug had it.
Release APKs could not connect to any HTTP backend, throwing:
  java.net.UnknownServiceException: CLEARTEXT communication not permitted

Fix:
1. Added android:usesCleartextTraffic="true" to main AndroidManifest.xml
2. Created res/xml/network_security_config.xml explicitly permitting cleartext
3. Referenced it via android:networkSecurityConfig="@xml/network_security_config"

Wiki: updated mobile-app-performance.md (section 48) and log.md.
